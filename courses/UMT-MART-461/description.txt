This class is designed to give the student a general understanding of programming server-side code and databases and interacting with APIs to create multiplayer games. Knowing game programming is highly recommended but not a requirement. We will focus primarily on connecting the server side to the client side. This class is a programming class; however, it is assumed that the student has a good understanding of programming concepts. This course focuses on C# and database development. Although this platform is used, it will not prevent the student from leveraging other tools provided by different vendors. The concepts covered in this course are generic and should translate to any language/platform. Level: Undergraduate-Graduate
