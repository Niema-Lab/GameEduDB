This course provides a hands-on approach to programming for artists in a technical art context. The course teaches the development of tools, plugins, and automation systems to handle repetitive inputs and complex workflows. By using principles based in programming and UI design, functional and object-oriented programming methodologies, students will develop artist-friendly interfaces and usable tools. This course provides introductory programming and interface development skills specifically geared towards 3D production. Offered in academic years ending with odd numbers.
