Exploration of principles and techniques of scripting for 2D game development. Emphasis on scripting syntax, logic, and code organization, along with methods for controlling and manipulating game objects in real time. Hands-on projects involving the creation of interactive 2D prototypes that demonstrate core gameplay mechanics and responsive systems. Focuses on designing, scripting, and troubleshooting functional 2D game experiences using industry-relevant workflows and best practices. Prerequisite: ANGM 2310 with a grade of B or better or Instructor consent required.
