This directory contains courses. Each individual course is contained within a folder whose name is a unique identifier for the course. Within each course's folder, the following files contain course attributes:

* `name.txt` - Official name of the course
* `course_code.txt` - Institutional number/ID/code of the course
* `url.txt` - URL of the course (ideally in the official course catalog)
* `prerequisite_course_ids.txt` - GameEduDB course IDs of prerequisite courses
* `institution_id.txt` - GameEduDB institution ID (as defined in [`institutions`](../institutions)) in which the course is offered
* `department_id.txt` - GameEduDB department ID (as defined in [`departments`](../departments)) in which the course resides
* `description.txt` - Description of the course (ideally the official description)
* `credits.txt` - Number of credits/units
* `categories.txt` - Categories of topics covered in the course
    * **Art:** Craft and technical skill: modeling, texturing, animation, recording/editing sound
    * **Design:** Problem-solving, planning and organisation of the player's experience: systems, level, content, narrative, camera, UX/UI design
    * **Development:** Programming and technical implementation
    * **Game Studies:** Critical game studies, history, games, and society
    * **Industry:** Production, project management, business of games
    * **Internship:** Internship or placement
    * **Leadership:** Team leadership, people management, or studio management
    * **Math:** Explicit mathematics courses
    * **Portfolio:** Portfolio-building courses
    * **Project:** Capstone, major project, thesis
    * **Psychology:** Psychology, cognitive science, or behavioral economics
    * **Research:** Research methods, user research, playtesting methodology, or analytics
    * **Soft Skills:** Communication, teamwork, professional skills as explicit courses
