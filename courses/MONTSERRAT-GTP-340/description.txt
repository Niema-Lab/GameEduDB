This is a course aimed at developing the animation and workflow skills particular to the needs of game development and other interactive media. Students will consider user input as they develop 2D character, prop and effects animation for particular game genres or art styles. The exercises and projects in this class, will emphasize the appropriate file set up, structure and pipeline for game engines. Topics covered may include character movement cycles, sprite sheets, rigging, game mechanics and simple coding to control 2D characters. Previous experience in game development is useful but not required. Prerequisites: 30 Credits, Animation I: Principles (recommended pre-req or co-req GTP260 Intro to Video Game Development) or Permission of Instructor Fulfills: Animation Elective (Animation students) or 300-Level Studio Elective or Studio Elective
