Prerequisites: CSCI 2103 and CSCI 3103. Many computer games are based on physical interactions between games objects e g collisions, evasions, pursuit, etc. Design and implementation of these actions is not an easy problem. Concept and character development, storyboarding, prototyping, testing and implementation will be discussed. Students will gain hands-on experience in game programming using a low-level graphical library. 3 hours. Fall.
