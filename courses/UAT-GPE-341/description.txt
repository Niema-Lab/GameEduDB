A game is only as good as its tool chain. Today’s games are extremely complex and the amount of data required to produce them can be overwhelming, thus the need for efficient data and asset management tools. In the modern games industry, almost every aspect of game development requires several custom-designed tools. The engine, art, asset management, editors, physics, AI and sound editors are all tools that create a game. This course teaches fundamentals of game tools development, including the theory behind these tools and the practical application of that theory. Basic editor creation and user-interface programming are also covered.
