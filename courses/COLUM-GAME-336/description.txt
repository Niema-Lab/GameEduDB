The course furthers the student’s ability to develop games using a real-time engine and game development system. The course allows the designer to develop derived game levels and content within existing game platforms. The course surveys games that will impact their game design process and reflect on themes of pacing, level design, encounters, etc. They customize game components such as game feel, control schemes, feedback, etc. They will make a series of gameplay examples that demonstrate their mastery of creating game content.
