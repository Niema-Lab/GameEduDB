Using the Game Engine learned in GDE 300, students will create Software Prototypes. Rapid Game Prototyping is used to iterate on game ideas and design aspects. Using an iterative process, short and straightforward prototypes are built to serve as representations of the anticipated gameplay. Students will explore and experiment with new ways of using mechanics and implementing aspects of a given genre into a game. Prerequisite: GDE 300. A Studio Course. 3-Credits.
