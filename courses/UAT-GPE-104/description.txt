Recommended for students with little or no prior programming experience. Students will use a game engine to study the basics of computer programming: variables, data types, looping, conditional logic, functions, arrays, types, and other basic concepts. The ability to explore these concepts prior to learning a more complex language such as C++ allows the student to learn game concepts without a language course and prepares the student for future courses in this program during the first year. Students will gain valuable programming experience by writing simple tutorial-based games.
