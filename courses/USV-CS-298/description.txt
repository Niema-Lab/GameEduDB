Efficient data performance is critical to good software development. In this course, students learn how to store data efficiently and the pros and cons of different data structures. Students quickly review the fundamental use and storage considerations of scalar data types. Students use object-oriented programming techniques to learn and implement abstract data types like stacks, queues, linked list, hash tables, binary search trees, Huffman codes, and other tree-based data structures. Students gain the ability to know when, why, and where each data type should be used and their data storage characteristics for memory efficient software development.
