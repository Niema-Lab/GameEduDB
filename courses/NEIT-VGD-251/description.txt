In this course, students will learn and employ the fundamentals of game level design. The level designer is responsible for creating an engaging environment for the player and to use techniques that will lead the player through the level toward a successful game conclusion. Using the iterative process of development, students will create basic game level environments with assets, enabling rapid prototyping to develop the game play. Level Design fundamentals taught through selected readings, videos and critiques will be employed by the student to improve their game in each succeeding iteration of development.
