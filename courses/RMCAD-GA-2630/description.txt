In this sophomore-level course, students will create runtime materials in a game engine while also using procedural texture generation tools and photographic images to aid in material creation. Students will explore creating materials adhering to physically based rendering models as well as adding motion and interactivity to game environments using programmable shaders. Students will create props and other game assets that make use of a variety of shader techniques. Upon successful completion of this course, students will have created runtime assets and have an understanding of materials for use in subsequent classes.
