The Project and Portfolio I: Computer Science course combines hands-on learning experiences with summative and formative portfolio assessments. In this course, students will build a project using the C-style Win32 API. The Win32 API is examined in order to gain a full understanding of its nature and scope, with particular attention paid to message-driven architecture and how programming with the Win32 API is different from console techniques. Students will also explore dialog boxes, Windows common controls, the Win32 GDI, dynamic-link libraries, and multitasking.
