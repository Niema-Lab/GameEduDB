This course provides a foundational introduction to programming and the team-based code collaboration tools commonly used in the gaming industry. Students develop these skills by rebuilding classic retro games from scratch within a professional game engine, using industry-standard object-oriented programming languages, a full-featured integrated development environment, and modern version control practices. The techniques and workflows developed in this class are essential for success in any collaborative game or software development environment. Topics include object-oriented programming principles, version control systems, and code-based team collaboration. Prerequisite: GAME 1500.
