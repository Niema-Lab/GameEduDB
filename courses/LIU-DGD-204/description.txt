This course focuses on the basic programming skills a student needs to start developing games on their own. As this is an introductory class, students are not expected to have any previous programming knowledge. Students will learn core programming concepts such as variables, if statements, for loops, arrays, functions, and object-oriented programming. They will also learn more game-specific concepts such as game states and collision detection. This course is taught in Processing, a variant of Java, and Unity, a game engine.
