This course covers an introduction to game scripting and takes the student through the process of creating games using an industry-standard game engine. The course explores using a game engine and associated scripting to maneuver characters around in 3D space, develop game environments, implement special effects, manipulate objects, script menus and graphical user interfaces, create non-player character behaviors, and much more. The student is required to have basic programming skills and game design experience from which this course expands in using scripting and game engine to create effective games.
