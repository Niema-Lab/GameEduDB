This class is a continuation of the Programming for Play foundations course. Advancing knowledge in game prototyping, art production and teamwork will be emphasized with extended project timelines. Emphasis will be placed on game pitches in response to assigned experiential goals. Class time will be dedicated to exploring best practice in teamwork, prototyping, playtesting and iterating over the course of the semester. Processes such as state machines, custom functions, triggers and events, usability and feedback loops will be explored in-depth. Tools for source control, team workflows, and task management will be explored. Final games will incorporate original artwork based upon team compositions alongside functional game play.
