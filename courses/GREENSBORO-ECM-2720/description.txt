Students learn how to create, edit and distribute podcasts, with a focus on audio podcasts. This hands-on course provides training in how to use the state-of-the-art equipment in the GCC podcasting studio to produce a podcast show. Students learn work flow, types of microphones, basic recording techniques, intros and outros, exercises to improve vocal delivery, how to stage guest interviews, and methods to improve audio quality through editing choices and use of software. Practice in the podcasting studio or an equivalent set up is a requirement.
