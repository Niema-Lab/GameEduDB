This directory contains institutions. Each individual institution is contained within a folder whose name is a unique identifier for the institution. Within each institution's folder, the following files contain institution attributes:

* `name.txt` - Official name of the institution
* `abbreviation.txt` - Official abbreviation of the name of the institution
* `url.txt` - URL of the institution (ideally the official website)
* `description.txt` - Description of the institution (ideally the official description)
